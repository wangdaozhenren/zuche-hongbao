# 租车自驾红包助手 · 平台规则与叠加指南

## 一、各平台红包规则

### 携程租车（比价聚合）
- **领取条件**：携程账号均可领，新用户有首日0元/首日半价优惠
- **使用门槛**：日租券如满200减30、满500减100（示例，以平台实时为准）；节假日特惠券限指定日期
- **有效期**：领取后约30天有效，节假日券限节假日期间使用
- **是否可叠加**：新客券与部分满减券可叠加；周租/月租另享长租折扣

### 一嗨租车
- **领取条件**：一嗨账号均可领，新用户首日0元起
- **使用门槛**：满减券如满150减20、满300减50（示例）
- **有效期**：领取后约30天有效
- **是否可叠加**：可与会员折扣叠加，通常不可与其他券叠加

### 神州租车
- **领取条件**：神州账号均可领，新用户首日0元起
- **使用门槛**：日租券如满200减40、周租满1000减150（示例）
- **有效期**：领取后约30天有效
- **是否可叠加**：可与会员价叠加，节假日多不可叠加

> 悟空租车等聚合平台以"比价比车型"为主，价格更低但网点/保险条款需逐单看清。

## 二、红包叠加逻辑

- **叠加顺序**：新客首单券 → 平台满减券 → 会员折扣 → 支付优惠（能否叠加以下单页为准）
- **长租更省**：周租/月租日均价比日租低（示例低30%~50%，以平台实时为准），适合长假/出差
- **提前订**：节假日提前2周以上预订，比临时订便宜；越临近取车日越贵
- **新客首单限同城**：多数新客首日0元/半价仅限同城取还，异地还车不适用

## 三、品类专属知识要点

### 3.1 车型分级与怎么选
- 租车分经济/舒适/SUV/商务/豪华等档，同档不同品牌价差大，别只看"SUV"字样
- 城市通勤选经济省油车；长途/多人选SUV；山路/雪地注意是否配雪地胎
- 取车前确认**日限里程**（不限里程 vs 每日限200/300公里），超里程另收费

### 3.2 保险怎么选（决策核心）
- **基础保险**（车损、第三者）通常已含在租金内，但常有"免赔额"（如1500元以内车损自担）
- **不计免赔/尊享服务**需另购，把1500元以内的小刮小蹭也转嫁给保险公司
- 新手、长途、不熟悉车况，建议买不计免赔；老司机短途可酌情不买
- 出事故必须**立即报案并联系租车公司**，私了/不报案可能被拒赔

### 3.3 异地还车费与超里程费
- **异地还车费**：跨城取还车按城市距离收，可能高达数百元（示例，以平台为准）；新客首单券常不含异地还车
- **超里程费**：日租若限里程，超出按公里另收；长租多不限里程，下单前确认
- 长途自驾优先选"不限里程"车型，或提前算清总里程是否超限

### 3.4 取车验车流程（实操核心）
1. 绕车一圈拍**全车视频**（前后左右、车顶、轮毂），记录已有刮蹭、凹陷
2. 拍仪表盘里程、油量、划痕，和门店工作人员当面确认并写入验车单
3. 检查备胎、三角牌、工具、充电口/加油口；试驾一圈听有无异响
4. 还车时同样拍视频、按约定油量加满油，避免"油差服务费"

## 四、新客与老客区别

- **新客专享**：首日0元/首日半价、新客大额券，力度最大，限首单、限同城取还
- **老客可领**：会员日优惠券、节假日特惠券、长租折扣
- **新老客通用**：平台通用满减券、签到券
- 新客首单券别浪费在只租1天的短途上，用在2~3天中长途更划算（但注意限同城）

## 五、避坑指南

1. **低价引流车到店加价**：超低价常是"限里程+不买保险+门店偏僻"的组合，下单前看清里程和保险
2. **隐性加购**：门店现场推销"升级车型"，想清楚再加；不需要就明确拒绝
3. **押金预授权**：刷信用卡预授权作押金，违章/划痕会预授权扣款，还车后预留解冻期
4. **节假日涨价**：春节/国庆租金上浮且车紧，提前2周订，临时订又贵又没车
5. **驾照要求**：一般需驾照满1年、部分车型满3年，取车带驾照原件和信用卡，电子驾照部分城市不认
